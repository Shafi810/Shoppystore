# 🛒 Shoppystore

Shoppystore is a **modern e-commerce landing page** designed to showcase locally sourced, premium goods.  
This project demonstrates my skills in **React, Vite, Tailwind CSS**, and building **data-driven UI components**.

---

## ✨ Features
- 📂 **Product Categories**: Fresh produce, bakery, dairy, pantry, beverages, home & body.
- ⭐ **Featured Products**: Organic honey, sourdough bread, roasted coffee, lavender soap, etc.
- 💬 **Customer Testimonials**: Highlights quality, eco-friendly packaging, and curated essentials.
- 📧 **Newsletter Signup**: Builds engagement and community.
- 🎨 **Gradient Placeholders**: Instead of images, products use Tailwind CSS gradients for visual appeal.

---

## 🛠️ Tech Stack
- **React + Vite** → Fast development environment.
- **Tailwind CSS** → Utility-first styling for responsive design.
- **JavaScript (ES6+)** → Dynamic rendering of product data.
- **Reusable Components** → Product cards, testimonial blocks, category sections.
